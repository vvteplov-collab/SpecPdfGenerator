# Интеграция с Excel

## Сборка

```powershell
dotnet publish .\SpecPdfGenerator.csproj -c Release -r win-x64 --self-contained true
powershell -ExecutionPolicy Bypass -File .\ExcelAddin\Build-ExcelAddin.ps1
```

Для создания `.xlam` Excel должен разрешать программный доступ к VBA-проекту:

`Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью → Параметры макросов → Доверять доступ к объектной модели проектов VBA`.

После сборки откройте `Installer\SpecPdfGenerator.iss` в Inno Setup Compiler и нажмите Compile. Готовый файл появится в `Installer\Output`.

## Установка и использование

1. Закройте Excel и запустите установщик.
2. Откройте Excel заново. Появится вкладка `Teplov` и группа `Спецификация`.
3. Откройте сохранённую `.xlsx` или `.xlsm` со спецификацией.
4. Нажмите «Сформировать PDF». Несохранённые изменения книги сохраняются автоматически перед запуском генератора.
5. Если генератор был перенесён, нажмите «Настройка генератора» и выберите `SpecPdfGenerator.exe`.

PDF создаётся рядом с исходной книгой и имеет то же имя. Путь к EXE хранится отдельно для текущего пользователя через `GetSetting/SaveSetting`, поэтому не записывается в проектные Excel-файлы.

## Проверка

1. Убедитесь, что вкладка `Teplov` появилась после перезапуска Excel.
2. Нажмите «Настройка генератора» и проверьте, что выбран `SpecPdfGenerator.exe`.
3. Откройте сохранённую книгу и нажмите «Сформировать PDF».
4. Дождитесь закрытия окна прогресса и проверьте PDF рядом с книгой.

CLI также поддерживает:

```text
SpecPdfGenerator.exe --version
SpecPdfGenerator.exe --input "C:\Project\Спецификация.xlsm" --output "C:\Project\Спецификация.pdf"
```
