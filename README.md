# SpecPdfGenerator

Инструмент полезен проектировщикам всех специальностей: он автоматически собирает многолистовую Excel-спецификацию в единый готовый PDF и избавляет от рутинной ручной подготовки листов. Это экономит заметное количество времени при выпуске спецификаций проекта.

Генератор одного PDF из нескольких вкладок 9-графовой спецификации Excel.

## Шаблон спецификации

Для работы генератора используйте готовый [шаблон Excel](Templates/%D0%A1%D0%BF%D0%B5%D1%86%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F%20%D0%A8%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD.xlsx). Он доступен в репозитории для скачивания и содержит структуру листов, с которой работает проект.

## Что использует из книги

- `Первый лист` — шаблон первого листа А3;
- `Второй лист` — шаблон последующих листов;
- строки данных шаблона: 11–30, 20 строк на А3;
- первый лист: номер листа `CA41`, всего листов `CD41`;
- последующие листы: номер листа `CE44`.

Генератор не изменяет исходную книгу при формировании PDF: все служебные операции выполняются во временной копии в памяти Excel. Если в книге есть несохранённые изменения, надстройка сначала сохраняет их, чтобы PDF был сформирован из актуальной версии.

## Порядок исходных вкладок

В PDF включаются все **видимые** вкладки книги в порядке слева направо. Листы `Первый лист` и `Второй лист` используются только как шаблоны А3 и не включаются как разделы спецификации. Скрытые вкладки не импортируются.

Название каждой включённой вкладки выводится отдельной жирной подчёркнутой строкой в начале её раздела.

## Быстрый старт

Нужны Windows и установленный Microsoft Excel.

1. Скачайте и установите [SpecPdfGenerator-Setup.exe](https://github.com/vvteplov-collab/SpecPdfGenerator/releases/latest). Перед установкой закройте Excel.
2. Откройте или скачайте [шаблон спецификации](Templates/%D0%A1%D0%BF%D0%B5%D1%86%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F%20%D0%A8%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD.xlsx), заполните его и сохраните рабочий файл.
3. Перезапустите Excel. На ленте появится вкладка `Teplov` с группой `Спецификация`.
4. Откройте сохранённую спецификацию и нажмите **Сформировать PDF**.
5. Готовый PDF будет создан рядом с файлом Excel, с тем же именем.

Если генератор был перемещён после установки, на вкладке `Teplov` нажмите **Настройка генератора** и укажите файл `SpecPdfGenerator.exe`.

## Что происходит при формировании PDF

1. Читает исходные вкладки в заданной очередности.
2. Автоматически находит 9 граф по заголовкам.
3. Собирает единый массив.
4. Делит его по 20 строк на А3; заголовок раздела не оставляет последней строкой страницы.
5. Одним блоком записывает данные в `Данные!F:O`.
6. Копирует первый шаблон целиком, затем `Второй лист` вертикальными блоками в один временный worksheet.
7. Ставит ручные разрывы страниц и номера листов.
8. Экспортирует только временный worksheet через штатный Excel `ExportAsFixedFormat` в один PDF.
9. Закрывает книгу без сохранения.
